# AI Video Summarizer

Turn any video or YouTube link into an AI-generated text summary in seconds.

## 🔗 Live Demo
**[videosummary.iamadityaranjan.com](https://videosummary.iamadityaranjan.com)**

## ✨ Features
- **Upload Videos:** MP4, AVI, MOV — extract audio with FFmpeg and summarize
- **YouTube URL:** Paste any YouTube link, get the summary without downloading
- **7-Day History:** Your recent summaries are saved locally in your browser (IndexDB)
- **Instant Results:** No signup required. Fast processing.
